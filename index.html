MySQL Database Users, Quizzes, Scores

users Table

  • user_id (INT PK AUTO_INCREMENT)
  • name (VARCHAR(100))
  • email (VARCHAR(100) UNIQUE)
  • role (ENUM('student', 'teacher'))

quizzes Table

  • quiz_id (INT PK AUTO_INCREMENT)
  • title (VARCHAR(150))
  • created_by (INT FK -> users)
  • total_marks (INT)

results Table

  • result_id (INT PK AUTO_INCREMENT)
  • user_id (INT FK -> users)
  • quiz_id (INT FK -> quizzes)
  • score (INT)
  • timestamp (DATETIME)
